# Benchmark data

- [`figure2_tutorial_block04.json`](figure2_tutorial_block04.json) is the
  corrected-weight reference for the Figure 2 tutorial. Its source hash and
  clean-run verification are recorded in the file.
- [`historical/`](historical/) contains the earlier Figure 1 and Figure 2
  campaign bundles, saved trajectories, and checksum manifest. Those runs used
  the previous weak-form weights and are retained for audit.

No selected paper artwork is stored here. The corrected full campaigns will be
frozen with the revised supplementary figures.
